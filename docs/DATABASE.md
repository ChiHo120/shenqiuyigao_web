# 可选数据库接入

默认演示无需数据库。以下用于新建、隔离的 Supabase 测试项目，尚未通过真实数据库执行验证。不要直接在现有生产库运行。

1. 新建自己的 Supabase 项目。
2. 在 SQL 编辑器按文件名升序执行 supabase/migrations 中的脚本；每份仅执行一次。脚本创建表、角色检查和行级权限，不含生产账号。
3. 在 Auth 控制台创建测试用户。管理员角色只能由可信操作员在数据库控制台向 public.user_roles 写入该测试用户 UUID 与 admin 角色；浏览器无权自行授予角色。
4. 将 .env.example 复制为 .env，只填自己的 URL 与 anon/公开客户端密钥。重启开发服务器。不要填写 service_role 或 secret key。
5. 验证匿名只能查看已发布记录，普通登录用户不能写业务表或读取留言，管理员按策略访问。

contact_messages 不允许匿名直接插入。前台当前仅保存本机演示留言，生产接收接口不包含在此版本中。

已有内容编辑仍包含 localStorage 演示路径；仅接上数据库不会自动把这些本地编辑改为服务器操作。
